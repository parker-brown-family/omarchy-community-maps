# Slices

1. Registry tracer: one task/profile/capability, validator and generated board, then expand to the full work map.
2. Review boundary: trusted base checks, untrusted test runner, negative fixtures and documented limits.
3. Public bootstrap: publish reviewed seed, immediately enforce rules/settings, verify through API and live PR probes. The initial seed is the only direct integration push.
4. Recruitment surface: issue packets, role offers, independent reviewer onboarding and pilot entry criteria.
5. Invitation: separate writer produces public words; Cinema Delight produces a one-minute portrait review film and recording booth. No social posting or synthetic voice requested.

Future application work uses its own approved design and vertical slices. No device is marked supported by this bootstrap.
