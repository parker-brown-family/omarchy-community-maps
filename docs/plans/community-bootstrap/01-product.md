# Product

Omarchy Community Maps is an independent community effort toward a useful maps experience across desktops, laptops, tablets and phones. The first useful outcome is a repeatable desktop trip: install, find a place, choose a start, get a walking route, and recover when location or the network is unavailable.

Every hardware family belongs in the work map from the beginning. A family is a recruitment target; support belongs to an exact device, operating-system build, application revision and tested capability. Universal live navigation is an aspiration, not a support claim. The host OS must already boot and expose working display/input; missing drivers are upstream dependencies.

The first community experiment succeeds only when an independent tester repeats the desktop trip and two independent stewards can triage and review it. The prior proposed fourteen-day pilot and thirty-minute weekly founder attention ceiling remain proposed experiment limits, not promises. The clock starts after stewards accept their roles.

This bootstrap publishes the contribution structure and a one-minute invitation. It does not announce a released map application. The generated contribution board is the review surface; no product UI is selected yet.
