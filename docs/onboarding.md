# First contribution

Choose a task whose prerequisites and hardware you can satisfy. Read its packet. Offer role, experience, exact hardware if relevant, output, time and agent/compute cap through the issue. Keep keys private.

A maintainer confirms scope and independent review capacity. Before that, read/reproduce offline fixtures or propose research rather than build a large speculative change.

Use Git and Python 3.11+, your fork and a branch. Run README checks. Include meaningful failing/passing cases. Device operators follow device-testing.md. Reviewers can start with SEC-01 or a reproducibility task.
