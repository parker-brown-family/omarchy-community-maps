# Inspirations

Omamesh and Omastorm show mapping already appearing in Omarchy plugins. Phonechy and Omarchy Mobile bring phone interaction and hardware qualification into view. Derek Ross's device board inspired our capability matrix.

These are inspirations, not partners, sponsors or recruited maintainers.

| Project | Useful part | Boundary |
|---|---|---|
| Omamesh | Bounded coordinates/overlays | Off-grid radio does not provide basemap/routing |
| Omastorm | Rust/QML, source freshness, pinned delivery | Weather data is separate |
| Phonechy | Touch phone experience | Source/license/hardware need audit |
| Omarchy Mobile | Device profiles/GNSS integration | Kernel work upstream; app guidance needs proof |
| CoMaps | Existing offline navigation | Integrate before fork; licenses/AI policy |
| GNOME Maps | Linux planning/GeoClue | Version-specific capabilities |
| Omamap/Earth/Omakeel | Small integration/service ideas | License, destination and test for each part |

Take compatible ideas or bounded components by default. Fork only with an unmet need and maintenance owner. No third-party source/media imported into this seed. Primary URLs and decisions: data/sources.json.
