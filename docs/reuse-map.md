# Reuse Map

Start with the complete CoMaps/GNOME Maps comparison and a separate regional MOTIS investigation. The table preserves all 29 candidates supplied in the research handoff. It is a source-backed candidate map, not a selected stack or a claim that the components plug into one another.

The default is to take fitting components and integration patterns. Use a whole app when its trip already works. A fork needs a reproduced gap, license review and maintenance owner. Reject unsuitable parts with the reason recorded. No upstream implementation code, media or map data is imported by this roadmap.

## Integration Decisions and First Tests
