# Pilot

Status: source research and open contribution intake. No application release, operator assignment or paid service is provisioned.

Parker accepts a potentially large queue. There is no fixed two-task, fourteen-day or thirty-minutes-per-week ceiling. Contributors declare their own time and compute limits. Hosting and data-build spend need a separate accountable operator and accepted cap.

Two coordinated investigations start the product roadmap. The existing desktop task compares CoMaps and GNOME Maps on one public-place walking trip. A regional service experiment evaluates MOTIS with bounded inputs; OTP and Valhalla become comparators when a particular failure justifies them. Neither track selects the other by default. Kelowna is the first proposed data example, not an exclusive supported region.

Source/coverage discovery, synthetic fixtures, place-data sampling and imagery research may proceed before mobile guidance or production-provider decisions. Technical runs still need accepted scope, local limits and the packet's input rights. Use compliant small requests or permitted downloads; no institutional partnership is needed for source reading and lawful individual tests. Do not load-test public endpoints or bulk-download prohibited tiles.

Measure review backlog, independent repetition, accepted/rejected work, agent compute, provider use and actual operating costs separately. Stop the affected run on a cap, unsafe input, missing rights or unmet runtime prerequisite. Keep independent intake and source research available. Agents propose include/scuttle/rebuild/reject decisions; required checks and human review decide integration.
