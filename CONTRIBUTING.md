# Contributing

Pick a task from [the work map](docs/work-map.md). Offer your role, hardware, output and available time/compute through its issue. A maintainer accepts scope and reviewer capacity before assigning work. An open task is not permission to spend project funds or change somebody's device.

## Contribution cycle
1. Read dependencies/current upstream and run the task's invalidation check.
2. Agree base revision, allowed paths, owner, independent reviewer, cap and stop rule.
3. Work in your fork/branch. Preserve failed attempts. One task, one PR.
4. Run local checks and meaningful negative cases; state unrun tests.
5. Submit PR template, run receipt, evidence and agent assistance disclosure.
6. Two independent approvals including code-owner review and required checks must pass. New pushes dismiss approvals.
7. Update support only after reviewed evidence; completed tasks never automatically certify hardware.

## Ways to help
Developers and agent operators implement one accepted integration or investigation. Device owners run tests without writing code. Reviewers repeat results and inspect permissions/dependencies. Maintainers own triage/releases/provider decisions. Writers test instructions and translations. Map contributors use OpenStreetMap's own review processes; do not bulk import generated claims.

Contributors use their own accounts and caps. Unknown tokens/cost are null. Never share keys or unrestricted bot access. No fundraising account or production hosting commitment exists.

## Rights and conduct
You confirm you may contribute the material under MIT, preserving third-party notices. Record origin/license for copied code or assets; map data/service terms are separate. AI output still needs provenance review. No AI author/contributor/co-author credit.

Discuss evidence respectfully. No harassment, doxxing, mass mentions or automated issue floods. Maintainers may pause intake when review capacity is exhausted. Request a private channel through the owner's GitHub profile for conduct concerns; do not post personal data.
